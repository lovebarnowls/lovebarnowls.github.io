1. What an API key is

An AI app does not run on your computer. The AI lives on a company's servers, and your app sends it a request over the internet. The company needs to know who is asking, so every request carries an API key: a long, secret code that works like a password and an account number in one.

2. Why AI companies charge by key

Every answer costs the company real computing power. They add up how much each key has used and send the bill to the key's owner. A key is a bit like a credit card number: whoever holds the number can spend the owner's money, and the owner gets the bill.

3. Why you keep the key secret

If a key is copied, a stranger can use the AI for free and the owner pays. People have found keys in public code and been billed thousands of dollars. A web page is public by design. Anyone can right-click and choose View Source, so a key written into a page is a key given away.

4. How this lab keeps the key secret

The key is not in this page. It sits on a small program called a Worker, running on Cloudflare's servers. Your page sends your words to the Worker. The Worker adds the key, passes the request to the AI and passes the answer back. The page never sees the key, so someone who finds this website cannot take it.

5. How the Worker limits what anyone can do

The page can still see the Worker's address, so the Worker has its own limits. It only accepts requests from approved websites. It chooses the AI model itself, so a page cannot ask for an expensive one. It caps the length of every answer. The Run button also locks for 45 seconds. This is one way we manage potential abuse. No single measure is perfect, so we use several.

What is Base64?

Computers store everything, including pictures, as bytes. Many bytes cannot travel safely through text, such as a web page, an email or a message. Base64 is a way to encode any bytes as plain text, using only 64 safe characters: A to Z, a to z, 0 to 9, plus + and /. Every 3 bytes become 4 characters, so the text ends up about a third bigger. An = at the end is padding.

Why encoding matters

Encoding means rewriting data so it can go somewhere it could not go before. It is how your picture sits inside the HTML file as text (it starts with data:image/jpeg;base64, and then the picture), how email attachments travel, and how binary data fits inside text formats such as JSON.

Encoding is not encryption

Base64 has no key. Anyone can turn it back into the original in a second, so it hides nothing. Hiding an API key in Base64 would not protect it. That is why the key lives in the Worker, as in lab a.
