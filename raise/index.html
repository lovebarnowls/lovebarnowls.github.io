About This Project:

This project demonstrates machine learning by using a trained model to distinguish between bottles and keys. The model was created using Google's Teachable Machine and integrated into Scratch using the RAISE Playground environment.

The project uses a camera to capture images and then processes them through the machine learning model to identify whether the object is a bottle or keys.
