INSERT — Adding New Data

This is a live database running entirely in your browser. Every INSERT you run actually changes the data — and you can verify it immediately with a SELECT. If things get messy, hit the Reset Database button in the top right to start fresh.

This database has one table called cars with four columns: car_id (a number), make (the brand), model (the specific model), and year (the year it was made).

The INSERT syntax

To add a new row, you list the values in the same order as the columns. Numbers go in without quotes. Text goes in with single quotes.

INSERT INTO cars VALUES (car_id, 'make', 'model', year)

Step 1 — look at what is already there

SELECT * FROM cars ORDER BY make, yearclick to copy to editor

Run this first. There are 36 cars already in the database. Take note of the highest car_id — your new rows need IDs that do not already exist.

Step 2 — guided example

Add the Chaparral 2J, a famous suction-fan race car from 1970. It was so effective at generating downforce that it was banned after one season.

INSERT INTO cars VALUES (37, 'Chaparral', '2J', 1970)click to copy to editor

Run this, then verify it was added:

SELECT * FROM cars WHERE make = 'Chaparral'click to copy to editor

Step 3 — your turn

Add the following cars one at a time. Choose your own car_id numbers — just make sure each one is unique.

  • Pagani Zonda F — 2005
  • Saleen S7 — 2000
  • Gumpert Apollo Enraged — 2012
  • Mazda 787B — 1991
After inserting all four Run SELECT COUNT(*) FROM cars — you should have 41 rows. Then try SELECT * FROM cars ORDER BY year ASC to see the full list from oldest to newest. Where does the Mazda 787B land?

Step 4 — free exploration

Open sandbox Add any car you like. Your own car, your dream car, a car from a game. Make up a fictional make and model. Try inserting a duplicate ID and see what error you get. Try leaving out a value. Try inserting a year as text instead of a number and see whether SQLite complains. This is your database — experiment.
