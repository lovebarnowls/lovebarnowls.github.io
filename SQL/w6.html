Week 6 — Revision

This week's database is a classical music collection — composers and their most famous pieces, including how many times each piece has been played.

There are no step-by-step instructions this week. Each question asks you to write the SQL query that answers it. Use the editor on the right to test your queries, then type or paste them into the answer box to check.

These 30 questions are revision for your assignment next week. They are spread across all three lessons this week — do not panic if you have only answered a handful by the end of the first lesson, that is completely normal. If you do power through them all early, come and see your teacher for extension questions. That said, getting every question correct is not the point — focus on understanding why a query works, not just whether the checker turns green. The editor on the right is a full sandbox — use it to ask your own questions of the data, explore things that interest you, and get comfortable navigating a database you have never seen before.

The auto-checker compares your query against one accepted correct answer. There are often multiple valid ways to write the same query — if yours is marked wrong but returns the correct result, check with your teacher. Copy your flag either way.
